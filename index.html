Sync with GitHub (saves lists across devices)

Each list is saved as data/oj.json or data/nick.json in that repository. Use a fine-grained token limited to that one repository with Contents: read and write, and give it an expiry date (a year is sensible), so a lost device can't reach your lists forever. If the repository is public, anyone can read those files, so a private repository is better for work tasks.
