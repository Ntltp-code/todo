Sync with GitHub (saves lists across devices)

Each person's list is saved as its own file in that repository, e.g. data/nick.json. Use a fine-grained token limited to that one repository with Contents: read and write, and give it an expiry date (a year is sensible), so a lost device can't reach your lists forever. If the repository is public, anyone can read those files, so a private repository is better for work tasks.
