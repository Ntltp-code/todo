    Lists
          Data

          Download every task — active and completed — with its text, dates, priority, category, and subtasks.

          Import tasks from a CSV file exported by this app (Export All Tasks or the Completed export). Imported tasks are added alongside your current list, not replacing it. Tasks you already have (same name and created date) are skipped, so importing the same file twice won't create duplicates.

          Completed tasks older than 90 days are moved out of your list once a day, so it stays quick. Nothing is deleted — you can restore everything here.

          Opens a pre-filled email in your mail app listing overdue, due-today, and high-priority tasks. You'll still need to hit send — this app can't send email automatically on its own, or while it's closed.

          Browsers can't attach files to an email draft automatically — this opens the report in a new tab with a "Print / Save as PDF" button, so you can save it and drag it into the email yourself.

          Security

          Add a password to show a lock screen when you open this app. This is a basic deterrent, not real encryption — anyone who can view this file's source can bypass it. For real protection, use Data Encryption below.

          Data Encryption. Encrypts your whole list — tasks, archive, categories, assigned-to / assigned-by lists, reminder email and settings (AES-256) — on this device and in your file on GitHub, so nobody can read it without your passphrase. You'll be asked for the passphrase when you open the list, on every device. If you forget the passphrase, your list cannot be recovered — keep a CSV export as a backup. CSV exports and the Summary Report are not encrypted.

          Danger zone

          Permanently delete every task in this list (active and completed). Categories and settings are kept. This cannot be undone — consider using Export first if you want a backup.
